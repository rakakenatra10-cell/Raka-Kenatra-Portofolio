## 🚀 Cara Membuka Website

Ada dua cara mudah untuk membuka website ini:

### Cara 1 (Paling Mudah):
- Buka folder `raka-portfolio`, lalu **klik ganda (double-click)** pada file `index.html` atau `buka-website.bat`.
- Website akan langsung terbuka di browser favorit Anda (Chrome, Edge, Firefox, dll).

### Cara 2 (Menggunakan Local Server):
Jalankan perintah berikut di PowerShell atau Command Prompt:
```bash
cd "C:\Users\Raka Kenatra Adyaksa\.gemini\antigravity\scratch\raka-portfolio"
python -m http.server 8000
```
Lalu buka browser di `http://localhost:8000`.
